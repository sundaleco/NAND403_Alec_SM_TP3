## Maya Random Animation Tool

Outil Python pour Autodesk Maya permettant de générer des animations aléatoires sur les objets sélectionnés.

Développé avec **Python, PySide6 et maya.cmds**, cet outil permet de :

- Générer des animations aléatoires sur les transformations (translation, rotation et échelle).
- Définir les valeurs minimales et maximales pour chaque axe (X, Y, Z).
- Configurer la durée de l'animation et l'intervalle entre les keyframes.
- Créer des animations en boucle fluide (*seamless loop*).
- Régénérer différentes variations d'animation.
- Annuler les modifications avec CTRL+Z. 

Le projet est organisé en trois fichiers : main.p , ui.py et animator.py .

Une vidéo démo est présente dans le repo. La fonctionnalité du ctrl-z est démontrée à la fin.
